# Companion Tiers

Tiers define a creature's potential, rarity, stat ceiling, and expected skill power. Tier is not a direct combat multiplier. A higher-tier creature is stronger because it can train higher stats and use stronger skills, not because combat applies an automatic tier bonus.

## Tier Table

| Tier | Name | Max Stat | Description |
| ---- | ---- | -------- | ----------- |
| 1 | Baby | 50 | Small or young creatures such as kittens, pups, chicks, and hatchlings. |
| 2 | Basic | 100 | Common adult creatures such as cats, dogs, foxes, and hawks. |
| 3 | Greater | 200 | Powerful trained creatures such as tigers, wolves, bears, and giant birds. |
| 4 | Elite | 350 | Extremely rare creatures such as dire wolves, saber-toothed cats, and ancient beasts. |
| 5 | Legendary | 550 | Mythic creatures with exceptional potential and unique battlefield presence. |

## What Tier Controls

| System | Tier Impact |
| ------ | ----------- |
| Stats | Sets the maximum trained value for each base stat. |
| Skills | Sets default skill ATP, ACC, ATT, SP Cost, builder costs, and ATP caps. |
| Training | Determines how much long-term growth a creature can hold. |
| Equipment | Provides guidance for item bonus scale. |
| Combat | Creates expected power gaps through stats and skill quality. |

## Tier Gap Expectations

| Gap | Expected Combat Feel |
| --- | -------------------- |
| Same tier | Winnable for either side depending on training, type, skills, equipment, and decisions. |
| One tier up | Hard but possible, especially if the lower-tier creature is near its cap and has advantage. |
| Two tiers up | Usually losing unless the lower-tier creature has major advantages and luck. |
| Three or more tiers up | Not expected to be practical without special circumstances. |

## Examples

- A trained Tier 2 creature with strong type advantage can beat an early Tier 3 creature.
- A Tier 2 creature should not usually beat a Tier 4 creature without a major setup advantage.
- A Tier 1 creature can still matter early because fast skills, status effects, and consumables can create tactical openings.

## Future Expansion
