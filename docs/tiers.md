# Companion Tiers
Currently there are 5 known tiers, but there could be more.

| Tier | Name      | Max Stat | Description                                              |
| ---- | --------- | -------- | -------------------------------------------------------- |
| 1    | Baby      | 50       | Small things, like kittens and puppies                   |
| 2    | Basic     | 100      | Most common tier, like cats and dogs                     |
| 3    | Greater   | 200      | Most common among trainers like tigers and wolves        |
| 4    | Elite     | 350      | Extremely rare, like saber-toothed tigers or dire-wolves |
| 5    | Legendary | 550      | Only the best have these                                 |
