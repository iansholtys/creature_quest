# Innate Talent

Each creature has a randomly assigned innate talent which improves one stat's growth by 30%, but reduces another stat's growth by 10%. Both stats are chosen randomly. If the same stat is chosen for both the positive and negative trait, they cancel each other out, resulting in a **Balanced** disposition.

## Trait Names

| Stat | Positive (+10%) | Negative (-10%) |
| ---- | --------------- | --------------- |
| HP   | Vitalized       | Frail           |
| SP   | Enduring        | Weary           |
| PATK | Mighty          | Feeble          |
| PDEF | Ironclad        | Brittle         |
| SATK | Arcane          | Dull            |
| SDEF | Warded          | Exposed         |
| SPD  | Swift           | Sluggish        |
| EVA  | Elusive         | Clumsy          |
| N/A  | Balanced        | Balanced        |

## Examples

- A creature with **Mighty** (PATK +10%) and **Weary** (SP -10%) is a powerful striker but lacks stamina.
- A creature with **Swift** (SPD +10%) and **Brittle** (PDEF -10%) strikes fast but takes heavy physical hits.
- If the same stat is chosen for both traits, it cancels out and the creature is considered **Balanced**.
